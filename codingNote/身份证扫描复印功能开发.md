# 编码笔记 - 身份证扫描复印小工具开发

## 1. 功能说明
本功能为小工具平台（STD）实现了一个高品质、安全合规的“身份证扫描复印”工具。
- **正反面拼接排版**：支持上传任意图片格式或通过 **iPhone 连续互通 (Continuity Camera)** 拍照/扫描，高精度拼接至单页 A4 PDF。
- **1:1 原大物理复印**：精准换算毫米与 PDF 磅点数，实现 100% 原大尺寸打印（85.6mm × 54.0mm），完美匹配政务/金融办事要求；同时支持“紫石英”发光风格的自适应最大化铺满模式。
- **安全防篡改水印**：放弃传统的 PDF 可编辑文本层水印，改用 Pillow 在**证件图像像素级别上打上倾斜拼贴防伪水印**，防止在 PDF 中被提取或删除。
- **画面预微调与色彩增强**：支持旋转调整、亮度和对比度滑块调整，提供“原色彩照”、“黑白复印 (Grayscale - 默认)”、“黑白高对比二值化 (Monochrome)”三种色彩转换模式。
- **实时所见即所得物理预览**：前端基于 HTML5 Canvas 实现微缩 A4 页面瞬时重绘，效果卓越。
- **离线 CLI 支持**：提供 `mini-tool id-card` 命令，支持以格式化文本、JSON 或 XML 导出元数据。
- **缓存与追踪**：采用图片与配置的哈希组合管理 LRU 本地缓存，直连 MySQL 进行全链路三色日志审计记录。

## 2. 关键代码

### A. 后端物理尺寸及 A4 画布高保真定位算法 (`backend/services/id_card_service.py`)
```python
# A4 页面标准尺寸: 595.27 x 841.89 points
# 身份证物理标准尺寸: 85.6mm x 54.0mm
# 换算公式: 1mm = 72 pt / 25.4 mm = 2.8346 pt
# 宽度 = 85.6 * 2.8346 = 242.6 pt
# 高度 = 54.0 * 2.8346 = 153.1 pt
card_w = 242.6
card_h = 153.1

# 垂直排版计算坐标 (上边距约 65mm，中缝缝隙约 37mm)
x = (A4[0] - card_w) / 2
y_front = 480.0 # 模拟肖像面
y_back = 220.0  # 模拟国徽面

pdf_canvas.drawImage(front_reader, x, y_front, width=card_w, height=card_h)
pdf_canvas.drawImage(back_reader, x, y_back, width=card_w, height=card_h)
```

### B. 像素级防篡改平铺倾斜水印绘制
```python
# 创建倾斜 30 度的水印文本贴片，防止通过 PDF 编辑器直接删除
font_size = max(16, int(min(w, h) * 0.045))
txt_img = Image.new("RGBA", (font_size * len(text) + 60, font_size + 40), (0, 0, 0, 0))
txt_draw = ImageDraw.Draw(txt_img)
txt_draw.text((30, 20), text, font=font, fill=(r, g, b, alpha))

rotated_txt = txt_img.rotate(30, expand=True, resample=Image.Resampling.BICUBIC)

# 平铺覆盖
for y in range(-rt_h, h + rt_h, y_step):
    for x in range(-rt_w, w + rt_w, x_step):
        overlay.paste(rotated_txt, (x, y), rotated_txt)
```

## 3. 注意事项
1. **中文字体加载**：后端 Pillow 水印绘制需要加载 TrueType 中文字体，在 macOS 下已完美适配了 `/System/Library/Fonts/PingFang.ttc` 等系统预装字体，并提供了极其可靠的 `ImageFont.load_default()` 终极保底防崩溃机制。
2. **安全防护级别**：由于生成件为敏感材料，本地 `backend/cache/` 目录设置了 30 分钟 TTL 且最大全局限额 100MB，任何生成动作都会触发自动清除过期及 LRU 淘汰机制，确保用户隐私数据零泄露。
3. **iPhone 连续互通机制**：在 Mac 的 Web 浏览器里，无法直接单向唤醒手机相机。此处是通过引导用户点击上传、在 Finder 文件对话框空白处右键菜单选择 **“从 iPhone 导入”** 来无缝配合苹果生态，该指引已在前端上传槽完美呈现。
